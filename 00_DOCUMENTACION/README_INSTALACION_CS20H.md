# ENTREGA COMPLETA F98.4-Z6-CS20H

## Nombre
English LAB Live — entrada estudiante pulida + compartir sala

## Base preservada

- Frontend: CS20G + agenda docente CS19F.
- Backend: compatible CS20G, sin cambio funcional en Apps Script.

## Qué agrega CS20H

- Pantalla de ingreso estudiante más clara para usar por Zoom.
- Código `LAB-####` más visible.
- Lectura automática de código desde URL: `?room=LAB-####`.
- Panel docente para compartir sala:
  - copiar código;
  - copiar mensaje completo;
  - copiar enlace directo.
- Texto institucional reforzado: práctica sin notas oficiales.
- Documentación `00_DOCUMENTACION` como fuente verdadera para GitHub.

## Instalación recomendada

1. Subir `GITHUB_COMPLETO_F98_4_Z6_CS20H.zip` a GitHub.
2. Si ya tenés CS20G funcionando, Apps Script puede quedarse igual.
3. Para respaldo cerrado, podés reemplazar `Code.gs` por el archivo CS20H compatible incluido.
4. Publicar nueva versión si reemplazás Apps Script.
5. Recargar campus con **Ctrl + F5**.
6. Entrar como docente > English LAB Live.
7. Crear sala, copiar mensaje y probar ingreso desde otra pestaña como estudiante.

## Prueba mínima

- Crear sala live.
- Copiar mensaje.
- Abrir enlace o entrar manualmente al módulo estudiante.
- Confirmar que aparece el código cargado.
- Iniciar sala.
- Lanzar pregunta.
- Responder como estudiante.
- Actualizar control docente.
- Ver participantes/respuestas.
- Cerrar pregunta.
- Ver respuesta correcta.
- Cerrar sala.
- Ver resultados finales.

## No tocar por ahora

- Agenda docente CS19F, porque ya fue presentada y aprobada.
- Reglas financieras CONAPE.
- Certificados.
- Exámenes oficiales.
- Cierre académico.
